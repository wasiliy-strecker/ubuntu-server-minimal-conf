Ubuntu Server Einrichtung

Projekt: ws-forms.com

Schritt 1

folder_open Verzeichnisstruktur & Berechtigungen

Projektverzeichnis anlegen. Der aktuelle User bleibt Besitzer, die Gruppe wird auf www-data gesetzt.

# Verzeichnis erstellen
sudo mkdir -p /var/www/ws-forms

# Gruppe auf www-data setzen
sudo chown -R :www-data /var/www/ws-forms

# Ordner auf 775 (drwxrwxr-x)
sudo find /var/www/ws-forms -type d -exec chmod 775 {} \;

# Dateien auf 664 (-rw-rw-r--)
sudo find /var/www/ws-forms -type f -exec chmod 664 {} \;

# Setgid-Bit (neue Dateien erben Gruppe www-data)
sudo chmod g+s /var/www/ws-forms
Schritt 2

settings_ethernet Apache Konfiguration

Datei erstellen: /etc/apache2/sites-available/ws-forms.conf

<VirtualHost *:80>
    ServerAdmin test@example.de
    DocumentRoot /var/www/ws-forms/
    ServerName ws-forms.com

    ErrorLog ${APACHE_LOG_DIR}/error.log
    CustomLog ${APACHE_LOG_DIR}/access.log combined
    
    <Directory /var/www/ws-forms/>
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
Schritt 3

published_with_changes Aktivierung

# Seite aktivieren
sudo a2ensite ws-forms.conf

# Syntax prüfen
sudo apache2ctl configtest

# Apache neu laden
sudo systemctl reload apache2
Schritt 4

language Lokale DNS (Hosts)

In /etc/hosts am Ende einfügen:

127.0.0.1   ws-forms.com

terminal Nützliche Befehle
